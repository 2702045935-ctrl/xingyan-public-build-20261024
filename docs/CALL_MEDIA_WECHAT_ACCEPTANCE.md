# 音视频微信级验收

只有全部项目通过，才可以把本轮音视频标记为“通过”。能建立通话、能看到画面不等于达标。

## 对照方法

- 同一台手机、同一网络、同一时间段分别测试星言和微信。
- 一对一语音、一对一视频、群语音、群视频分别测试。
- 网络矩阵覆盖 Wi-Fi、5G/LTE、3G、弱 2G、300ms 延迟、10% 丢包、30% 丢包、完全断网。
- 每组至少 20 次接通，以及一次 30 分钟持续通话。
- 每次记录客户端日志、WebRTC 统计、服务端房间记录和系统资源。

## 硬性门槛

| 项目 | 通过标准 |
| --- | --- |
| 接通成功率 | 不低于是同条件微信结果，且 20 次测试无失败 |
| 首音 | P95 不高于微信 + 200ms，且理想网络下不超过 1 秒 |
| 视频首帧 | P95 不高于微信 + 300ms，且理想网络下不超过 1.5 秒 |
| 稳定网络卡顿 | 30 分钟内无超过 200ms 的音频中断 |
| 30% 丢包 | 声音连续可懂，画面自动降级但不中断 |
| Wi-Fi/蜂窝切换 | 2 秒内恢复，不需要重新拨号 |
| 完全断网恢复 | 20 秒内自动重连，媒体不串房、不重复 |
| 群语音 | 9 人同时在线，加入、退出和静音状态一致 |
| 群视频 | 9 人同时在线，画面和音频成员严格对应 |
| 发热与耗电 | 30 分钟通话不高于同条件微信 + 15% |
| 内存 | 30 分钟通话无持续增长，结束后正常释放 |
| 稳定性 | 压力测试、前后台切换和强杀恢复均无崩溃 |

## 当前阶段

- 已移除客户端腾讯 TRTC/TX 框架依赖。
- 一对一语音保留现有 PCM 帧管线，经自有 WebSocket 中继。
- 一对一视频使用 libwebrtc，媒体中继只允许自有 TURN。
- 自研 SFU 接入前，群视频明确不可用，不回退腾讯。

当前状态只能记录为“去腾讯里程碑通过”，不能记录为“微信级音视频通过”。

## 信令归属与分片约束

- 聊天分片只保存会话、消息、好友和权限，不承担通话状态。
- 一对一通话的信令与 PCM 帧统一进入固定通话分片 `5299`。
- 非通话分片收到任意 `call` 动作后只转发给通话分片，不在本地创建第二份 call 状态。
- 同一 `callId` 只能有一个权威 `calls` 记录；忙线判断也只以这份记录为准。
- 通话事件按在线用户所在分片定向转发；只有 presence 尚未同步时才允许短暂广播兜底。
- `invite`、`accept`、重复 `accept`、`audio`、`hangup`、`timeout` 必须幂等。
- 通话分片不可用时必须显式返回“通话服务暂不可用”，不能静默丢帧或让界面永久停在呼叫中。
- `/api/health` 必须明确返回 `role=call-signal|chat-shard`、`port`、`shardId`、
  `callSignalPort`、`activeCalls`、`ringingCalls` 和 `directoryCalls`，运维不再靠猜。

## 大厂级量化门槛

| 指标 | 验收线 |
| --- | --- |
| 信令分片一致性 | 同一通话在任一时刻只有一个权威状态，跨片状态分叉为 0 |
| 跨片转发 | P95 ≤ 100ms，P99 ≤ 250ms，错误率 < 0.1% |
| 来电送达 | 在线用户 P95 ≤ 300ms，离线恢复后 2 秒内可拉到 pending call |
| 接听同步 | 主叫收到 `accepted` P95 ≤ 300ms，两端均在 500ms 内显示“通话中” |
| 首帧音频 | 接听到首帧双向均 P95 ≤ 500ms，P99 ≤ 1 秒 |
| 重复与乱序 | 重复 accept/hangup 不改变最终状态，迟到帧不串到下一通电话 |
| 忙线一致性 | 跨片并发呼叫同一用户时，只允许一通成功，其余立即收到忙线 |
| 定向媒体转发 | 已知在线分片时，PCM 只发目标分片；广播兜底比例 < 0.1% |
| 链接稳定性 | 1000 次跨片通话无状态分叉、无串房、无遗留 call 记录 |

## 当前实现状态

- 本地已实现“固定通话分片 + 非通话分片仅转发”的单一权威状态。
- `call-cross-shard` 自动测试覆盖：跨片来电、离线 pending、接听、双向 PCM、跨片忙线和挂断。
- 服务端 trace 新增“接通耗时”和“接通到首帧”指标。
- 本地 20 轮跨片压力结果：来电、接听、双向首帧 P95 均为 31–32ms；
  每轮结束后通话权威记录和分片目录均归零。
- 尚未部署到线上，尚未完成两台真机同条件对照，因此不能标记为微信级通过。
