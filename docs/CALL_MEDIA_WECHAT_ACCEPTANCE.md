# 音视频微信级验收

只有全部项目通过，才可以把本轮音视频标记为“通过”。能建立通话、能看到画面不等于达标。

## 对照方法

- 同一台手机、同一网络、同一时间段分别测试星言和微信。
- 一对一语音、一对一视频、群语音、群视频分别测试。
- 网络矩阵覆盖 Wi-Fi、5G/LTE、3G、弱 2G、300ms 延迟、10% 丢包、30% 丢包、完全断网。
- 每组至少 20 次接通，以及一次 30 分钟持续通话。
- 每次记录客户端日志、WebRTC 统计、服务端房间记录和系统资源。

## 硬性门槛

| 项目 | 通过标准 |
| --- | --- |
| 接通成功率 | 不低于是同条件微信结果，且 20 次测试无失败 |
| 首音 | P95 不高于微信 + 200ms，且理想网络下不超过 1 秒 |
| 视频首帧 | P95 不高于微信 + 300ms，且理想网络下不超过 1.5 秒 |
| 稳定网络卡顿 | 30 分钟内无超过 200ms 的音频中断 |
| 30% 丢包 | 声音连续可懂，画面自动降级但不中断 |
| Wi-Fi/蜂窝切换 | 2 秒内恢复，不需要重新拨号 |
| 完全断网恢复 | 20 秒内自动重连，媒体不串房、不重复 |
| 群语音 | 9 人同时在线，加入、退出和静音状态一致 |
| 群视频 | 9 人同时在线，画面和音频成员严格对应 |
| 发热与耗电 | 30 分钟通话不高于同条件微信 + 15% |
| 内存 | 30 分钟通话无持续增长，结束后正常释放 |
| 稳定性 | 压力测试、前后台切换和强杀恢复均无崩溃 |
