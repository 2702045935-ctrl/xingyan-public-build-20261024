# Canary 自动刹车

`server/lib/canary-guard.js` 用于 Gateway fanout 灰度发布：

- 统计扫描、成功、失败和 outbox pending；
- 失败比例超过阈值时自动暂停 canary；
- pending 超过上限时自动暂停，避免继续把新群切到新链路；
- 暂停后未命中的群自动回退旧本地链路；
- 恢复必须显式调用内部管理接口，不自动解除。

建议阈值：

| 阶段 | 最大失败率 | 最大 pending |
| --- | ---: | ---: |
| 1% | 1% | 500 |
| 5% | 3% | 2,000 |
| 20% | 5% | 5,000 |
| 50%+ | 5% | 10,000 |
